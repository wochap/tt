tt web frontend — Catppuccin Mocha / Latte on Nocturne

Assumptions. Nocturne supplies type (Inter 500 headings), 8px radii, 0.7× density and outlined primaries; every color is a Catppuccin token with blue as the accent. Entry color: project first (Atlas=mauve, Billing=peach, Infra=teal), tag second (urgent=red, meeting=yellow, review=sapphire, ops=green), neutral otherwise. Running entries are drawn to a live "now" edge with a dashed bottom and a pulse dot; concurrent entries split the column into lanes, never stack. Fictional day: Thu 8 Oct 2026, 15:42, two entries running. Shortcuts shown inline as J-style hints so the keyboard model is visible in the UI.

Left column Mocha, right column Latte. Turn 3 (tokens, empty states, popovers, board, sheets) sits above turn 2 (login, ⌘K, settings, task detail, reports, phone) above turn 1 (day, week, month, sheet, tasks). Inventory and drag spec below.
