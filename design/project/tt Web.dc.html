Timeline, entry sheet, task list — Catppuccin Mocha / Latte

Assumptions. Nocturne supplies type (Inter 500 headings), 8px radii, 0.7× density and outlined primaries; every color is a Catppuccin token with blue as the accent. Entry color: project first (Atlas=mauve, Billing=peach, Infra=teal), tag second (urgent=red, meeting=yellow, review=sapphire, ops=green), neutral otherwise. Running entries are drawn to a live "now" edge with a dashed bottom and a pulse dot; concurrent entries split the column into lanes, never stack. Fictional day: Thu 8 Oct 2026, 15:42, two entries running. Shortcuts shown inline as J-style hints so the keyboard model is visible in the UI.

shadcn/ui map. Top bar → NavigationMenu; view switcher & snap → ToggleGroup; date jump → Popover + Calendar; running strip chips → Badge + Button; entry sheet → Sheet; task picker → Command (also powers ⌘K); start/end → Input + Popover; note → Textarea; tags → Badge variants; filters → DropdownMenu with checkbox items; task table → Table; undo → Sonner toast; sync state → Tooltip on a dot; theme → shadcn CSS variables remapped to the Catppuccin flavor.

Left column Mocha, right column Latte. Turn 2 (login, ⌘K, settings, task detail, reports, phone) sits above turn 1 (day, week, month, sheet, tasks). Drag spec below.

  • Pointer down on empty space ≥ 4px move starts a ghost; start snaps down, end snaps up to the grid.
  • Live label shows range + duration; dragging upward flips anchor.
  • Release opens the task picker (Command) anchored to the ghost; Esc discards; pick creates the entry; ⌘⏎ picks and keeps it running if end = now.
  • Below 5 min the ghost is discarded (click, not drag).

  • Running entries can move their start only; end stays "now".
  • Drop = one undoable op; ⌘Z restores exactly.

14:15 · 1h 45m
  • 8px handles at top and bottom edges (hit area extends 3px outside the block, hover tints the edge).
  • Top handle moves start, bottom moves end; the opposite edge is pinned.
  • Min duration = one grid step; snap unless ⌥.
  • Bottom handle on a running entry stops it at the dropped time.
  • Overlap created by resizing simply re-lanes neighbours live.

lanes split the column
